# Meong Photobooth v1.0.0 — first Kivy source baseline

Release date: 2026-10-19. This version promotes the previously tested `feature/kivy-gui` application to `master` and marks a reproducible **source-code baseline**. It is not a declaration of fully certified unattended production operation.

## Included

- Kivy GUI: advertising-first landing, images/video playback, optional face-detection invitation, tutorial, 12 template choices, capture/review/result and branding.
- Local print routes for the photo strip and optional DEMO payment-QR slip; ESC/POS thermal printing and selectable Floyd–Steinberg/Bayer/threshold dithering.
- FEAT-001 DEMO price logic (Rp5,000 per selected photo-template session, Rp5,000 per physical print copy) and Windows RAW batching. Owner reported tested PASS of photo copy quantity (BUG-011).
- FEAT-003 horizontally mirrored **live preview** only, leaving saved/printed originals unmirrored; owner reported tested PASS.
- CI screenshot QR decoder stabilization (QA-QR-001), release branch CI checks, documentation, backlog and bug/decision registers.

## Known issues and boundaries

- BUG-001 / BUG-007: real Windows background music and isolated test-sound audition still need physical-speaker retesting.
- BUG-009: Google Drive 30-day cloud retention/deletion trigger remains OPEN/unverified. Do **not** advertise cloud auto-deletion as guaranteed.
- Current payment QRIS is **DEMO / non-payable**. Real settlement (FEAT-020) and receipt scanning (FEAT-002) are **not implemented**.
- Full per-case Windows camera, speaker, QR-phone scan, thermal-paper, reliable offline/Drive retention and end-to-end deployment certification are pending. No customer deployment or Google Apps Script redeployment is included in this release.

## Recovery

- Previous `master` tip is preserved as branch `backup/master-pre-v1-20261019` (commit `d4852cb56d2eea92ae135a5ab38ce3676e2f3381`).
- The v1 source baseline is immutable at tag `v1.0.0`; use `git checkout v1.0.0` for a reproducible reference, or create a new rollback commit/PR to revert a later master change. Do not force-push `master`.
- Existing `feature/kivy-gui` remains available; future features/bug fixes should be reviewed on feature/fix branches and merged through tests.

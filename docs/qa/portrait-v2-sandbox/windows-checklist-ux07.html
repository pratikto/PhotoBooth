Checklist cek laptop

Centang Lulus hanya setelah berhasil dicoba. Centang Gagal bila ada masalah. Kosong berarti belum diuji.

Buka file ini langsung di browser laptop. Isi hasil, klik Salin Hasil untuk Chat, lalu paste dan kirim di percakapan ini. Form berjalan offline dan tidak mengirim data otomatis.

Jalankan python tools/run_portrait_v2_sandbox.py pada branch feature/portrait-kiosk-v2-next. Sandbox: printer/Drive OFF, hanya simulator Midtrans. Jangan menulis PIN, kunci, isi tiket asli atau foto pribadi di catatan. Jangan hapus jurnal/foto atau bayar lagi untuk melewati status yang belum pasti.

Mulai di sini — tidak perlu mengerti kode

Siapkan laptop, internet, kamera, ponsel untuk menyimpan tiket, dan akun Midtrans Sandbox. Uji memakai foto dirimu/objek uji dengan izin. Printer dan Drive tetap OFF; kertas dan upload bukan target form ini.

  1. Buka folder PhotoBooth di File Explorer. Klik bilah alamat, ketik powershell, lalu Enter. Ini membuka terminal pada folder proyek.
  2. Jalankan pemeriksaan branch/file di bawah. Jika bukan branch yang disebut atau ada perubahan yang tidak kamu pahami, catat hasilnya dan berhenti sebelum update. Jangan reset/clean.
  3. Jika branch sesuai dan file bersih, update lalu catat SHA. Pilih lingkungan Python yang memang sudah ada: .venv-kivy atau .venv. Tidak perlu membuat lingkungan baru untuk cek ini.

Periksa dan update

git branch --show-current
git status --short
# Lanjut pull hanya jika branch sesuai dan perubahan lokal aman:
git pull --ff-only origin feature/portrait-kiosk-v2-next
git rev-parse HEAD

Jalankan versi Sandbox

Jika ada folder .venv-kivy, gunakan:

.\.venv-kivy\Scripts\python.exe tools\run_portrait_v2_sandbox.py

Jika lingkunganmu bernama .venv, ganti bagian awal menjadi .\.venv\Scripts\python.exe. Jika kamu sudah mengaktifkan lingkungan Kivy yang benar, python tools/run_portrait_v2_sandbox.py juga boleh. Jangan memakai main.py untuk cek GUI v2.

Biarkan PowerShell terbuka selama app berjalan. Jika diminta Merchant ID/Server Key, isi milik Sandbox di terminal laptop saja; input Server Key disembunyikan. Jika nilainya sudah tersimpan di pengaturan lokal, prompt bisa tidak muncul. PIN operator delapan digit tercetak di terminal; kamu sendiri boleh memakainya saat L08. PIN berubah setiap launcher dijalankan ulang.

Cara mengisi parameter laptop (L01)

Jalankan perintah berikut di PowerShell kedua pada folder proyek, atau sebelum membuka app. Gunakan lingkungan Python yang sama. Perintah ini hanya membaca versi paket.

.\.venv-kivy\Scripts\python.exe --version
.\.venv-kivy\Scripts\python.exe -m pip show Kivy opencv-python

Untuk .venv, ganti path seperti di atas. Cari baris Name dan Version masing-masing paket; tidak perlu menyalin semua keluaran. Jika paket OpenCV memakai varian berbeda dan tidak muncul, tulis belum diketahui.

SHA
Nomor versi kode dari git rev-parse HEAD. Salin seluruh barisnya.
Clean / dirty
git status --short kosong = clean. Ada baris = dirty (perubahan lokal). Ini bukan kerusakan; jangan hapus perubahan.
OS
Windows Settings → System → About; cukup Windows 10/11 dan versi jika diketahui.
Resolusi / scaling
Settings → System → Display → Display resolution / Scale. Contoh 1920×1080 dan 125%. Resolusi layar berbeda dari ukuran jendela app.
Kamera
Tulis bawaan laptop atau merek/model USB. Tidak tahu model? Tulis kamera bawaan, model belum tahu.

Urutan cek yang disarankan

L01 → L02 → L03 → L04 → L05 → L06 → L07. L06 baru bisa disimpulkan penuh setelah pembandingan di L07. L08 adalah uji lanjutan; L09 dicatat sepanjang rangkaian. Boleh berhenti dan mengirim hasil parsial.

Setiap item punya alasan, kondisi awal, langkah dan hasil yang diharapkan. Pilih Lulus bila semua bagian wajib berhasil; Gagal bila ada perilaku yang salah saat dicoba; Belum diuji bila belum lengkap. Contoh: L02 gagal membuat QR, maka L03–L08 yang belum bisa dijalankan tetap Belum diuji, bukan ikut Gagal. Catatan tiap item ikut tersalin ke prompt.

Kalau membuka form ini lagi, hasil tersimpan bisa muncul. Itu hasil lamamu, bukan hasil otomatis atau bukti untuk kode yang baru di-pull. Sebelum menguji SHA baru, salin/unduh laporan lama, lalu gunakan Kosongkan Form dan isi versi baru.

Jika langsung membuka halaman pemulihan

SESI TERSIMPAN / TIKET PELANGGAN DIPERLUKAN sesudah restart adalah penjagaan privasi yang diharapkan. Gunakan tiket asli dari kunjungan tersebut → VERIFIKASI TIKET → PULIHKAN SESI FOTO ASLI. Jangan memakai tiket kunjungan lain atau PIN operator di kolom tiket.

Jika tidak punya tiket lama, pilih BANTUAN OPERATOR bila tersedia untuk membaca status dengan PIN launcher terbaru. Pemeriksaan operator tidak membuka foto dan tidak menggantikan tiket. Catat halaman/error dan kirim hasil parsial. Jangan membuat pesanan baru untuk membayar pemulihan.

Jika hanya PERLU BANTUAN OPERATOR tanpa tombol seperti screenshot lama, catat SHA, perintah dan teks halaman. Itu bukan langkah yang harus kamu pecahkan dengan mengedit data. Stop bagian yang tertahan, biarkan item lanjutan Belum diuji, lalu kirim laporan.

App gagal dibuka? python.exe tidak ditemukan: periksa nama folder lingkungan. ModuleNotFoundError: salin nama modul dan perintah yang dipakai. another launcher is active: periksa apakah app/terminal sebelumnya masih berjalan; jangan hapus lock. Error setup/port/provider: catat pesan, jangan ganti booth/profil untuk melewati sesi tersimpan.

Istilah yang akan kamu lihat

Tiket pemulihan
QR/teks rahasia untuk membuka kembali kunjunganmu sendiri. Simpan sebelum halaman pembayaran. Berbeda dari QR bayar dan QR download.
Pending / settlement / paid
Belum dibayar / pembayaran sudah diselesaikan oleh simulator / status bayar terverifikasi app. Sukses di browser masih perlu diterima app.
Retake / lembar
Retake = mengambil ulang satu pilihan foto (satu kesempatan per desain). Lembar = salinan strip; memilih dua lembar tidak berarti dua sesi foto.
Isolasi / ACK / arsip
Menghentikan pemakaian sesi lama dengan aman / konfirmasi backend menerima pelepasan / menyimpan ikatan kunjungan lama. GUI mengurus prosesnya. Melepas booth tidak berarti refund atau hasil cetak sudah diterima.
Fixture / mock
Skenario otomatis dengan data/perangkat tiruan. Kamu tidak perlu membuat printer macet, memutus ACK, mengubah database, atau menghitung hash foto untuk checklist laptop ini.
